LOCAL PACKAGING CHANGES
  The generated Xcode product is named WinlatorIOS so the IPA payload is Payload/WinlatorIOS.app;
  the Xcode target and scheme remain WinlatorPhase02. The imported project's deployment target
  was raised from 16.0 to the requested iOS 17.0. The home-screen label is “Winlator iOS Probe”
  to identify this honestly as a diagnostic proof of concept, not a Windows runtime. After the
  first iPhoneOS CI compile exposed that `mach/mach_vm.h` is unsupported by the iPhoneOS SDK,
  `runtime_memory.c` was changed to use the public `vm_region_64` interface from `mach/mach.h`.
  The manual GitHub Actions workflow and release reports were added in the target repository;
  PRs to main run the unsigned build without signing secrets, while workflow_dispatch may use configured secrets.
